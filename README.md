# Bulletin Board Backend

REST API для сайта объявлений, разработанный на Django REST Framework. 
Проект представляет собой полноценный бэкенд с авторизацией, ролевой моделью, системой объявлений и отзывов.

## Основной функционал

- **Аутентификация и авторизация:** Регистрация и вход по JWT-токенам.
- **Ролевая модель:** Разграничение прав доступа (обычные пользователи и администраторы).
- **Восстановление пароля:** Сброс пароля через электронную почту с использованием зашифрованных ссылок.
- **CRUD для объявлений:** 
  - Пользователи могут создавать, редактировать и удалять только свои объявления.
  - Администраторы имеют права на редактирование и удаление любых объявлений.
- **Отзывы:** Возможность оставлять отзывы под объявлениями.
- **Поиск:** Фильтрация и поиск объявлений по названию.
- **Пагинация:** Ограничение вывода не более 4 объектов на странице.
- **Документация:** Автоматическая генерация Swagger/OpenAPI документации.

## Локальный запуск

Для запуска проекта вам понадобятся установленные **Docker** и **Docker Compose**.

1. Склонируйте репозиторий:
```bash
git clone https://github.com/Dasha0Ramzer/bulletin-board.git
cd bulletin-board
```

2. Создайте файл `.env` на основе шаблона `.env.example`:

```bash
cp .env.example .env
```

3. Запустите проект одной командой:

```bash
docker compose up -d --build
```

4. Приложение будет доступно по адресам:

- Админка: http://localhost:8000/admin/
- Swagger (документация): http://localhost:8000/swagger/
- Redoc: http://localhost:8000/redoc/

## Запуск тестов
Тесты написаны с использованием pytest. Чтобы запустить их, выполните:
